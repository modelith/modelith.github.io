# Modelith を支援する

Modelith は、オープンソースで開発しています。
開発を続けるための支援を、[GitHub Sponsors](https://github.com/sponsors/modelith) で受け付けています。

<SponsorCard />

GitHub のアカウントがあれば、上の「Sponsor」から、毎月または 1 回だけの支援を選べます。
カードが表示されないときは、[GitHub Sponsors の Modelith のページ](https://github.com/sponsors/modelith) を開いてください。

お金のほかにも、[不具合のご報告やご要望](https://github.com/modelith/modelith/issues/new/choose) や、Modelith を周りの人に紹介していただくことも、大きな支えになります。
